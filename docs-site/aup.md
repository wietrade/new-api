# 可接受使用政策（AUP）

本页说明哪些内容与行为不得通过 NowHub 的 API 服务实施或协助实施。本政策是《用户协议》的组成部分；`api.nowhub.org` 及本站发起的一切请求均适用。

违反本政策可能导致限流、暂停或终止账号，且不退还剩余额度。

## 1. 总原则

- 您对提交的输入、获得的输出及其后续使用承担全部责任。
- 本站是技术接入网关，不是内容的发布者；发现明显违规时我们有权采取措施，并依法配合有权机关。
- 遵守上游模型服务商的使用政策是使用本站的前提；上游政策与本政策同时适用，以更严格者为准。

## 2. 禁止生成或传播的内容

以下内容不得通过本站生成、改编、传播或协助获取：

- **危害国家安全与社会稳定**：煽动颠覆、分裂、暴恐、极端主义。
- **儿童安全（零容忍）**：任何涉及未成年人的性化内容、诱骗话术、剥削或虐待材料。发现即永久封禁，并在法律要求范围内向主管机关报告。
- **暴力与伤害**：详细的暴力实施方法、酷刑虐待、自残或自杀的方法指导与诱导。
- **违法犯罪协助**：制毒制爆、武器制造、入侵系统与凭证窃取、洗钱、诈骗脚本、规避执法侦查。
- **欺诈与欺骗**：钓鱼邮件或页面、虚假身份与证明文件、冒充他人、虚假投资话术、批量生成的误导性评论。
- **侵犯他人权益**：侵犯著作权、商标权、肖像权、名誉权、隐私权；未经同意披露他人身份、住址、联系方式。
- **仇恨与骚扰**：针对种族、民族、宗教、性别、性取向、残障等的仇恨言论，以及针对性骚扰与威胁。
- **色情内容**：以性表演、性暗示为主要目的的内容；未经同意生成的他人性化图像（含深度伪造）。
- **虚假信息操纵**：用于操纵舆论、选举、评分或评论的虚假账号内容；伪造新闻、公文、医疗与金融建议。
- **高风险专业建议**：未取得资质、未声明"非专业意见"即把输出作为医疗诊断、法律意见、投资建议交付终端用户。
- **自动化高风险决策**：未履行法定告知、评估与人工复核，即将输出用于信贷、招聘、保险、司法、执法等决策。

## 3. 禁止的技术与商业行为

- **密钥与账号滥用**：转售、出租、出借、多人共用账号或 API Key；公开分享密钥；使用他人密钥。
- **绕过限制**：多账号、伪造注册信息、代理池、篡改请求头等手段绕过限流、封禁、额度或地区限制。
- **攻击与探测**：端口扫描、漏洞探测、未授权渗透、压力测试、DDoS 或干扰服务稳定性。
- **抓取与逆向**：批量爬取非公开接口、价格或数据；逆向非开源组件；绕过计费或鉴权。
- **模型蒸馏**：系统性采集本站输出用于训练、微调与本站直接竞争的模型或服务。
- **未授权转售**：以本站为基础对外提供 API 转售、二次分发或同类网关服务（含"套壳"站点）。
- **规避制裁与出口管制**：向受制裁国家/地区、主体或个人提供服务；规避上游地域限制。
- **支付滥用**：恶意拒付、盗卡、虚假充值、利用退款机制套利。
- **资源滥用**：脚本化批量注册、薅取试用额度、长期空转占用并发。

## 4. 面向公众产品的额外义务

- 建立与业务风险相匹配的内容审核机制（关键词、模型审核、人工复核、举报入口）。
- 在显著位置告知终端用户"内容由 AI 生成，可能存在错误"。
- 涉未成年人、医疗、金融、法律等敏感场景时，确保已取得必要资质与授权。

## 5. 举报

请发送邮件至 [**support@nowhub.org**](mailto:support@nowhub.org)，尽量附上：违规内容截图、时间（含时区）、涉及的模型与端点、可复现的请求描述。

我们对举报人身份保密（法律另有要求除外）；涉及儿童安全或人身安全的举报优先处理。

## 6. 违规处理

视情节采取一项或多项措施：

1. 警告并限期整改；
2. 限制并发、限流或冻结相关令牌；
3. 暂停账号、下架相关模型权限；
4. 终止账号、删除数据、**不退还剩余额度**；
5. 向上游服务商、支付渠道或有权机关报告。

涉嫌犯罪的，依法移送有管辖权的机关。

## 7. 申诉

对处理结果有异议，可在收到通知后 15 日内发送邮件至 [**support@nowhub.org**](mailto:support@nowhub.org)，说明事实、理由与佐证材料。我们将在复核后书面回复；复核期间限制措施通常继续有效。

- 为处理举报、申诉与安全事件，可能临时留存相关请求元数据（默认不含正文）。
- 本政策可能随法律、上游政策与业务调整更新，更新后在本页标注。
- 本政策适用**服务提供方所在地法律**；争议解决方式与《用户协议》一致。
