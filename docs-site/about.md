# 关于本站

NowHub API 是一个自建的大模型 API 中转服务：把不同厂商的模型统一到一组兼容接口后面，按实际用量计费。

## 关键信息

| 项目 | 内容 |
| --- | --- |
| 站点域名 | `https://nowhub.org` |
| OpenAI SDK Base URL | `https://api.nowhub.org/v1` |
| 支持的协议 | OpenAI 兼容、Anthropic Messages、Gemini 原生 |
| 鉴权方式 | 控制台签发的令牌（`sk-` 开头） |
| 计费方式 | 预付额度，按 token 或按次扣费 |
| 模型清单 | [模型广场](https://nowhub.org/pricing) |
| 用量明细 | 控制台 → 日志 |

## 服务边界

- 本站是**技术接入层**，不是模型厂商的官方服务，也不对下游输出内容做担保
- 模型的能力、上下文长度与安全策略由上游决定，可能随时调整
- 请勿提交真实密钥、身份证号、医疗记录等敏感信息到提示词中

## 数据与日志

- 请求日志用于计费与故障排查，包含模型、token 数、耗时与扣费金额
- 提示词与回复正文是否留存、保存多久，以当前部署配置为准
- 需要清理历史记录时，请联系管理员

## 联系方式

- 站点：<https://nowhub.org>
- 管理后台：<https://nowhub.org/dashboard>
- 故障反馈请附：请求时间（含时区）、模型 ID、令牌名称、完整响应体（**不要贴完整 Key**）

## 免责与合规

使用本站即表示你同意：不将服务用于违法用途，不尝试绕过上游的内容安全策略，对自身输入输出的合规性负责。违反者可能被停用令牌。
