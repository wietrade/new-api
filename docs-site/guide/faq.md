# 常见问题

## 为什么返回 401？

- 没带 `Authorization: Bearer <TOKEN>` 头
- Key 前后多了空格或换行
- 令牌已过期、被禁用或额度用尽
- Anthropic 客户端把 Key 放在 `x-api-key` 里，但用了 OpenAI 端点（反过来也一样）

## 为什么模型明明存在却返回 403？

令牌有三层限制：模型白名单、分组、IP 白名单。任何一层不满足都会 403。到令牌详情页确认这三项。

## 报「无可用渠道」怎么办？

说明该分组下没有健康的渠道。可以换分组，或稍后重试；如果长期存在，说明该模型在该分组没有配置。

## 支持 seed / logprobs / tool calling 吗？

取决于模型与上游。模型广场的「支持的参数」一栏是按模型给出的实际支持列表。

## 计费为什么和我算的不一样？

常见差异来源：

- 没算上**缓存读取/写入**的独立单价
- 上下文超过阈值后**切到了更高档位**
- 分组倍率不是 1
- 图片、音频等非文本 token 的折算规则不同

## 能开更高额度吗？

额度与分组绑定，联系管理员调整令牌所属分组或单独放量。

## 数据会被保留吗？

请求日志用于计费与排障，保存时长以后台配置为准。请不要在提示词里传真实密钥、身份证号等敏感信息。
