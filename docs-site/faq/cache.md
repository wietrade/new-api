# 提示词缓存与计费

## 什么是缓存计价

同一段前缀（系统提示、长文档、工具定义）在短时间内重复使用时，上游可以复用计算结果，这部分按「缓存读取」单价计费，通常比正常输入便宜一个数量级。

## 怎么确认命中

看响应的 `usage`：

| 协议 | 字段 |
| --- | --- |
| OpenAI | `usage.prompt_tokens_details.cached_tokens` |
| Anthropic | `usage.cache_read_input_tokens` / `cache_creation_input_tokens` |
| Gemini | `usageMetadata.cachedContentTokenCount` |

## 怎么提高命中率

1. **前缀稳定**：把不常变的内容（系统提示、工具定义、知识库）放最前，把用户输入放最后
2. **别塞时间戳**：系统提示里带「当前时间」会让每次前缀都不同
3. **连续调用**：缓存有存活时间（常见 5 分钟 / 1 小时两档），间隔太久会失效

## 为什么账单比手算的高

- 没命中缓存，按正常输入价计费
- 写缓存本身有单独单价（部分模型）
- 上下文超过阈值后切到更高档位
- 分组倍率不是 1
