# 服务等级与支持说明

本页说明 NowHub API 的可用性目标、维护与故障处理方式、支持响应范围。**本页不构成带赔付承诺的 SLA**，如需签署正式 SLA，请通过 support@nowhub.org 联系我们。

## 1. 服务定位

- 本站是第三方大模型 API 的**技术接入与路由层**，推理能力由上游厂商提供。
- 服务按"现状"与"可用"基础提供；我们会尽合理努力保持稳定，但不对上游故障、网络中断或不可抗力造成的不可用承担赔付责任。
- 具体责任限制以《用户协议》第 11 条为准。

## 2. 可用性目标（尽力而为）

| 项目 | 目标 |
| --- | --- |
| 站点与控制台可用性 | 月度 ≥ 99.5%（不含计划维护） |
| API 网关可用性 | 月度 ≥ 99.5%（不含上游故障与计划维护） |
| 计划维护 | 提前在公告/工单通知，尽量安排在低峰时段 |
| 故障通报 | 确认影响后尽快在公告或工单中说明进展 |

> 上述为内部运维目标，非合同承诺；实际达成情况受上游厂商与网络线路影响。

## 3. 线路与稳定性差异

| 分组类型 | 说明 | 稳定性 |
| --- | --- | --- |
| 满血 | 厂商官方 API 直连 | 最高，受上游 SLA 覆盖 |
| 稳定 | 高性价比线路，带稳定性优化 | 较高 |
| 特惠 | 低成本线路 | 一般，可能排队或限流 |
| 越狱 | 非官方线路 | 波动较大 |

对延迟与稳定性有硬性要求的生产场景，请选择**满血**分组。

## 4. 支持范围与响应

- **支持渠道**：support@nowhub.org、控制台工单。
- **响应时间**：工作日内一般 24 小时内首次响应；重大故障优先处理。
- **排查所需信息**：请求时间（含时区）、模型 ID、令牌名称、请求 ID、完整响应体（**请勿粘贴完整 API Key**）。
- **不在支持范围**：上游模型能力与内容策略问题、用户自身集成错误、超出上游限制的用法、提示词效果调优。

## 5. 故障处理流程

1. 确认影响范围（单模型 / 单分组 / 全站）；
2. 排查上游渠道状态，必要时自动或手动切换线路；
3. 在公告或工单同步进展与预计恢复时间；
4. 恢复后复核计费，对失败请求按规则退费（见下）。

## 6. 计费与故障补偿

- 请求失败（未返回有效响应）不计费；已扣费但未成功的请求，凭请求 ID 联系客服核实后退回额度。
- 因上游错误导致的批量失败，我们将主动核查并退回相应额度。
- 除上述额度退回外，不提供现金赔偿或额外补偿，法律另有强制规定的除外。

## 7. 服务变更

我们可基于上游可用性、合规、安全或运营需要，调整模型、端点、价格、限流与路由策略。重大变更会提前公示；上游紧急调整可能即时生效。

- 工单：控制台 → 工单支持
- 状态与公告：站点公告栏
