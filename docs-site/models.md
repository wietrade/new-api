## 口径说明

- **计费**：`分档计价` 表示同一模型内按上下文长度或缓存命中分成多个档位，单价见模型的详情页
- **上下文**：单位是 token，`1M` = 1,000,000
- **分组**：该模型在哪些分组可用；令牌不在对应分组时无法调用
- **协议**：模型支持的接口类型，实际可用性还取决于渠道配置

## 想批量拉取？

```bash
curl https://api.nowhub.org/api/pricing | jq '.data[] | {model_name, enable_groups}'
```

字段与模型广场一致；`billing_expr` 是分档计价表达式，不建议自行解析，直接看详情页即可。
