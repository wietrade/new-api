# NowHub 隐私政策

**版本：v1.0｜最近更新：以本页展示为准**
**服务提供方：NowHub（nowhub.org）运营方**
**联系邮箱：**[support@nowhub.org](mailto:support@nowhub.org)

本政策说明我们在您使用 nowhub.org 及 `api.nowhub.org` 服务时如何收集、使用、存储与共享信息，以及您享有的权利。本政策是《用户协议》的组成部分；两者不一致时，就个人信息处理事项以本政策为准。

## 1. 适用范围

1.1 本政策适用于网站访问、账号注册与登录、控制台使用、充值与计费、API 调用等全部场景。

1.2 本政策不适用于第三方网站或服务。您通过本服务调用的上游模型服务商、支付渠道等，适用其各自的隐私政策。

## 2. 我们收集的信息

**2.1 账号信息**

- 注册与登录邮箱、邮箱验证状态；
- 密码的加盐哈希值（我们不保存明文密码）；
- 可选的昵称、备注等您主动填写的信息；
- 第三方登录标识（若您使用该方式登录）。

**2.2 使用与计费信息**

- 令牌/API Key 的标识、名称、额度与状态（密钥本体仅以不可逆方式存储或仅展示一次）；
- 调用记录元数据：时间、模型、端点、输入/输出 Token 数、请求次数、金额、状态码、耗时、路由分组等；
- 充值订单号、金额、支付渠道返回的交易标识与支付状态。

**2.3 设备与日志信息**

- IP 地址、User-Agent、请求时间、请求路径、响应状态；
- 用于安全风控的异常行为记录（如高频失败、并发异常）。

**2.4 支付信息**

- 我们不收集也不保存完整银行卡号、CVV 或支付密码。支付由第三方支付渠道处理，我们仅接收交易结果与必要的对账信息。

**2.5 请求与响应正文（重要）**

- **默认不保存**您提交的 prompt、文件、图片及模型返回内容，这些内容仅在完成本次推理所必需的范围内传输。
- 为排查故障，管理员可能在**限定期限内**开启调试日志。若启用，我们会在控制台或公告中明确告知，并在期满后清除。
- 上游模型服务商可能依据其自身政策记录请求内容，请参见第 5 条。

## 3. 我们如何使用信息

3.1 提供与维护服务：账号验证、开通令牌、路由请求、结算费用、展示用量。

3.2 安全与风控：识别滥用、盗用、攻击、欺诈与异常调用，保护服务与用户安全。

3.3 计费与对账：生成账单、处理退款争议、配合支付渠道核对。

3.4 服务改进：以**聚合、去标识化**方式统计容量、性能与错误率（不用于训练模型，也不用于用户画像广告）。

3.5 法律合规：响应有权机关的合法要求，或行使、抗辩法律主张。

**我们不会**出售您的个人信息，也不会将其用于与上述目的无关的营销推送（除非您单独同意）。

## 4. 法律基础

在适用法律要求的前提下，我们基于以下基础处理信息：履行与您的合同（提供服务与计费）、履行法定义务、我们的合法利益（安全、防滥用、服务改进），以及您的同意（如可选的调试日志、营销通知）。

## 5. 共享与第三方

5.1 **上游模型服务商**：为完成推理，您的请求内容与必要参数会传输至 OpenAI、Anthropic 及您所选模型对应的服务商。其处理行为受其自身条款约束。

5.2 **支付服务商**：用于完成收款、退款与风控校验，仅共享完成交易所必需的信息。

5.3 **邮件与基础设施服务商**：用于发送验证码、通知与运行网站（含 CDN、DNS、对象存储等）。

5.4 **法律要求**：在法律法规、司法或行政机关依法要求时披露。

5.5 我们要求受托处理方按约定与保密义务处理信息，不得超范围使用。

## 6. 跨境传输

6.1 我们的服务器及上游服务商可能位于您所在国家/地区之外（包括美国、新加坡、日本等）。使用本服务即意味着相关请求可能跨境传输。

6.2 我们会采取合理措施要求接收方提供不低于本政策水平的保护；您应自行确认该等传输符合您所在司法辖区的要求，避免提交受特殊传输限制的数据。

## 7. 保存期限

7.1 账号信息在账号存续期间保存；注销后按法律要求的最短期限保留必要的交易与对账记录，其余删除或匿名化。

7.2 调用元数据按账单与风控需要保留（通常不超过 12 个月），超期删除或聚合化。

7.3 调试日志（如启用）在告知的期限内保留，期满自动清除。

## 8. Cookie 与本地存储

8.1 我们使用必要的 Cookie 与浏览器本地存储维持登录状态、保存语言与主题偏好、防止跨站请求伪造。

8.2 我们不使用第三方广告 Cookie。若未来引入统计工具，会在本政策中更新说明并提供选择方式。

8.3 您可通过浏览器设置清除或拒绝 Cookie，但可能导致无法登录或部分功能不可用。

## 9. 安全措施

9.1 采取传输加密（HTTPS）、密码哈希、访问控制、最小权限、审计日志等措施保护信息。

9.2 互联网环境不存在绝对安全。若发生可能影响您权益的数据安全事件，我们将按法律要求及时告知，并采取补救措施。

9.3 请妥善保管账号与 API Key；因您保管不当导致的泄露由您自行承担相应后果。

## 10. 您的权利

在适用法律范围内，您有权：

- **访问与获取**：查看账号信息、用量与订单记录；
- **更正**：修改不准确的账号信息；
- **删除**：请求删除非必需保留的信息；
- **注销**：在控制台或联系客服注销账号（需结清费用）；
- **撤回同意**：对基于同意的处理（如可选日志、通知）随时撤回；
- **投诉**：向所在地数据保护机构投诉。

我们通常在 15 个工作日内响应；涉及复杂情形会说明延期原因。

## 11. 未成年人

本服务面向具备完全民事行为能力的开发者与企业用户。我们不面向未满 18 周岁的未成年人提供服务；如发现误收集，将尽快删除相关账号与信息。

## 12. 政策变更

12.1 我们可能更新本政策。重大变更将通过站内公告或注册邮箱提示，并在页面标注更新版本。

12.2 变更生效后继续使用本服务，视为接受更新后的政策；如不同意，您可停止使用并申请注销。

## 13. 联系我们

隐私相关问题、权利行使请求或投诉，请联系：[**support@nowhub.org**](mailto:support@nowhub.org)。

我们会在收到请求后尽快处理；如您对处理结果不满意，可向有管辖权的监管机构投诉。
