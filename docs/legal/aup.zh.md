# NowHub 可接受使用政策（AUP）

**版本：v1.0｜最近更新：以本页展示为准**
**服务提供方：NowHub（nowhub.org）运营方**
**举报与申诉邮箱：support@nowhub.org**

本政策是《用户协议》的组成部分，用于明确**哪些内容与行为不得通过本服务实施或协助实施**。使用本服务即表示您同意遵守本政策；违反本政策将按第 6 条处理。

本政策适用于通过 `api.nowhub.org` 及网站、控制台发起的一切请求，无论请求最终由哪家上游模型服务商处理。

## 1. 总原则

1.1 您对通过本服务提交的输入、获得的输出及其后续使用**承担全部责任**。

1.2 本服务是技术接入网关。我们不是内容的发布者，但有权在发现明显违规时采取措施（限流、暂停、终止），并依法配合有权机关。

1.3 遵守上游服务商的使用政策是您使用本服务的前提。上游政策与本政策同时适用，以更严格者为准。

## 2. 禁止生成或传播的内容

您不得利用本服务生成、改编、传播或协助获取下列内容：

2.1 **危害国家安全与社会稳定**：煽动颠覆、分裂、暴恐、极端主义，或宣扬恐怖活动的内容。

2.2 **儿童安全（零容忍）**：任何涉及未成年人的性化内容、诱骗（grooming）话术、剥削或虐待材料。发现即永久封禁账号，并在法律要求范围内向主管机关报告。

2.3 **暴力与伤害**：详细的暴力实施方法、酷刑、虐待、自残或自杀的方法指导与诱导。

2.4 **违法犯罪协助**：制毒制爆、武器制造、入侵系统与凭证窃取、洗钱、诈骗脚本、规避执法侦查等操作性指导。

2.5 **欺诈与欺骗**：钓鱼邮件与页面、虚假身份与证明文件、冒充他人或机构、虚假投资与杀猪盘话术、批量生成的误导性评论。

2.6 **侵犯他人权益**：侵犯著作权、商标权、肖像权、名誉权、隐私权的内容；未经同意披露他人身份、住址、联系方式等个人信息（人肉搜索）。

2.7 **仇恨与骚扰**：基于种族、民族、宗教、性别、性取向、残障等的仇恨言论，以及针对性骚扰、威胁、网络霸凌。

2.8 **色情内容**：以性表演、性暗示为主要目的的内容；未经同意生成的他人性化图像（含深度伪造）。

2.9 **虚假信息操纵**：批量生成用于操纵舆论、选举、评分或评论的虚假账号内容；伪造新闻、公文、医疗与金融建议并用于误导。

2.10 **高风险专业建议**：在未取得相应资质、未明确声明"非专业意见"的情况下，将输出作为医疗诊断、法律意见、投资建议直接交付给终端用户。

2.11 **自动化高风险决策**：在未履行法定告知、评估与人工复核义务的情况下，将输出用于信贷、招聘、保险、司法、执法等对个人权益有重大影响的自动化决策。

## 3. 禁止的技术与商业行为

3.1 **密钥与账号滥用**：转售、出租、出借、多人共用账号或 API Key；公开分享密钥；使用他人密钥。

3.2 **绕过限制**：通过多账号、伪造注册信息、代理池、修改请求头等手段绕过限流、封禁、额度限制、地区限制或上游政策。

3.3 **攻击与探测**：对本服务进行端口扫描、漏洞探测、渗透测试、压力测试、DDoS 或任何干扰服务稳定性的行为（未获书面授权）。

3.4 **抓取与逆向**：批量爬取非公开接口、价格或数据；逆向工程非开源组件；试图绕过计费或鉴权。

3.5 **模型蒸馏与竞品构建**：以系统性方式采集本服务的输出用于训练、微调与本服务直接竞争的模型或服务。

3.6 **转售与再分发**：未经书面授权，以本服务为基础对外提供 API 转售、二次分发或同类网关服务（含"套壳"站点）。

3.7 **规避制裁与出口管制**：向受制裁国家/地区、受制裁主体或个人提供服务；规避上游服务商的地域限制。

3.8 **支付滥用**：恶意拒付（chargeback）、盗卡、虚假充值、利用退款机制套利。

3.9 **批量注册与资源滥用**：脚本化批量注册、薅取试用/赠送额度、长期空转占用连接或并发。

## 4. 内容安全义务

4.1 若您将本服务用于面向公众的产品，应自行建立与业务风险相匹配的内容审核机制（关键词、模型审核、人工复核、举报入口）。

4.2 您应在产品显著位置向终端用户说明"内容由 AI 生成，可能存在错误"，避免误导。

4.3 涉及未成年人、医疗、金融、法律等敏感场景时，您应确保已取得必要资质与授权。

## 5. 举报

5.1 任何人可通过 **support@nowhub.org** 举报疑似违规使用。举报时请尽量提供：违规内容或输出截图、时间（含时区）、涉及的模型/端点、可复现的请求描述。

5.2 我们承诺对举报人身份保密（法律另有要求除外），并在收到完整材料后尽快初核；涉及儿童安全或人身安全的举报将优先处理。

## 6. 违规处理

6.1 视情节轻重，我们可采取以下一项或多项措施：

- 口头/邮件警告并要求限期整改；
- 限制并发、限流或临时冻结相关令牌；
- 暂停账号并下架相关模型/分组权限；
- 终止账号、删除数据、**不退还剩余额度**；
- 向上游服务商、支付渠道或有权机关报告。

6.2 因违规导致的账号终止，不影响我们追究已产生费用与损失的权利。

6.3 涉嫌犯罪的，我们将依法移送有管辖权的机关。

## 7. 申诉

7.1 若您认为处理有误，可在收到通知后 **15 日内**发送邮件至 support@nowhub.org 申诉，说明事实、理由与佐证材料。

7.2 我们将在收到申诉后尽快复核并书面回复复核结果；复核期间相关限制措施通常继续有效。

7.3 同一事项原则上只复核一次，除非您提供新的实质性证据。

## 8. 配合与留存

8.1 为处理举报、申诉与安全事件，我们可能临时留存相关请求元数据（不含正文，除非依法或经告知后开启调试日志）。

8.2 对依法提出的调取要求，我们在核验主体与程序合法性后予以配合。

## 9. 政策更新

9.1 本政策可能随法律、上游政策与业务变化更新，更新后在页面标注版本并以公告或站内通知提示。

9.2 更新生效后继续使用本服务，视为接受更新后的政策。
