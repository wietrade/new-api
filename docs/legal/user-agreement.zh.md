# NowHub 用户协议

**版本：v1.0｜最近更新：以本页展示为准**
**服务提供方：NowHub（nowhub.org）运营方**
**联系邮箱：support@nowhub.org**

> 本协议适用于您访问 nowhub.org（含 www.nowhub.org、api.nowhub.org 及其子域）并使用 NowHub 提供的 API 接入服务。请在注册、充值或发起 API 请求前完整阅读。您完成注册、充值或实际调用，即视为已阅读并同意本协议及《隐私政策》。

## 1. 定义

1.1 **"本服务"**：指 NowHub 通过 API 端点（默认 `https://api.nowhub.org`）向开发者提供的第三方大模型统一接入、请求路由、用量计费与控制台管理能力。

1.2 **"上游服务商"**：指实际提供模型推理能力的第三方，包括但不限于 OpenAI、Anthropic 及其后续接入的其他厂商。

1.3 **"API Key / 令牌"**：指您在控制台创建、用于调用本服务的凭证。

1.4 **"额度 / 余额"**：指您预充值形成、用于抵扣调用费用的账户余额。

## 2. 协议接受与变更

2.1 您须具备完全民事行为能力。若您代表企业或其他组织使用本服务，您声明已获得该实体的合法授权。

2.2 本协议可能因法律、上游政策或业务调整而更新。更新后我们会在网站公告或以站内/邮件方式提示；重大变更将在生效前合理期限内公示。

2.3 协议更新生效后您继续使用本服务，视为接受更新内容；如不同意，应停止使用并结清已产生的费用。

## 3. 服务性质与边界

3.1 本服务是**技术接入与路由网关**，不是上游服务商的官方服务，也不直接向公众提供生成式内容产品。本服务不控制上游模型的能力、输出质量、内容策略与可用性。

3.2 我们会将您的请求转发至相应上游服务商。上游的价格、限流、内容审核、日志与数据处理策略由其自行决定并可能随时调整。

3.3 我们可基于上游可用性、合规、安全或运营原因，新增、下线、替换、改道、限流或暂停特定模型、渠道、分组或端点。

3.4 本服务主要面向服务器端集成、内部系统与开发测试场景。**本服务不构成任何形式的 SLA 承诺**，除非双方另行签署书面服务协议。

## 4. 账号、凭证与安全

4.1 您应提供真实、准确、有效的注册信息（当前采用邮箱验证），并及时更新。

4.2 您应妥善保管账号密码、API Key 及任何集成凭证，并对该账号与密钥下发生的全部调用与费用负责。

4.3 **API Key 不得公开分享、不得硬编码于客户端或公开仓库**。因保管不当导致的泄露、盗用与费用损失由您承担。

4.4 发现凭证泄露或异常调用时，应立即在控制台轮换/删除密钥并联系我们。为保护服务与支付安全，我们可主动撤销或限制可疑凭证。

4.5 同一账号仅供您自身（或您所属组织内部）使用，**不得转租、转售、出借或多人共用**。

## 5. 计费、充值与价格

5.1 本服务采用**预充值 + 按量扣费**模式。计费单位可能包括 Token 数、请求次数、图片/音频/视频等媒体单位，具体以控制台与价格页展示为准。

5.2 不同「分组」适用不同倍率，实际扣费 = 上游单价 × 分组倍率 × 用量，并按充值比例折算。价格与倍率以调用时的价格页/控制台展示为准。

5.3 上游调价、汇率变动或模型上下线可能导致价格变动。我们会尽合理努力提前公示，但**上游紧急调整可能即时生效**。

5.4 充值一经完成即计入账户余额，不可转让。因充值产生的支付通道费、汇兑损失由您承担。

5.5 我们可对异常充值、拒付、欺诈或洗钱嫌疑的订单进行冻结、撤销或要求补充说明。

## 6. 退款与余额

6.1 本服务属在线技术服务，调用即产生上游成本。**已实际消耗的额度及已交付的服务不予退还**。

6.2 下列情形可联系我们协商退款或余额调整：
- 适用法律强制要求；
- 我们主动停止某项付费服务，导致剩余额度无法合理使用；
- 因我方原因造成重大故障，且在显著期间内无法正常使用。

6.3 下列情形原则上不适用退款：违反本协议、滥用或欺诈、恶意拒付、集成错误、超出上游能力或政策的使用场景，以及对模型输出内容不满意。

6.4 具体退款与余额处理，以购买页面说明及客服沟通结果为准；本协议未约定的事项，双方另行协商。

## 7. 使用规范与禁止行为

您不得利用本服务实施或协助实施下列行为：

7.1 违反法律法规的内容生成或传播，包括危害国家安全、暴力恐怖、儿童性剥削、诈骗、赌博、制毒制爆、侵犯他人合法权益等。

7.2 未经授权转售、代理、二次分发本服务或 API Key，或以本服务名义对外提供同类网关服务。

7.3 通过多账号、伪造信息、代理池等手段绕过限流、封禁、地区限制或上游服务商政策。

7.4 对本服务进行扫描、渗透、压力测试、DDoS 攻击，或干扰其他用户正常使用。

7.5 逆向工程、爬取、批量抓取非公开接口或数据，或试图获取他人请求/密钥。

7.6 提交违法个人数据、受监管数据、第三方商业秘密，或在未取得合法授权的情况下提交他人作品与个人信息。

7.7 将本服务用于自动化决策等对个人权益有重大影响的场景而未履行法定告知与合规义务。

7.8 违反上游服务商的使用政策（可能同时导致上游侧封禁）。

**违规后果**：我们可立即限制、暂停或终止相关账号与密钥，删除违规内容，且**不退还剩余额度**；情节严重的将依法移送有关部门。

## 8. 内容、数据与隐私

8.1 **默认不保存请求与响应正文**。本服务仅在必要范围内传输您的输入以完成推理，并为计费与运维记录元数据（账号/令牌标识、时间、模型、用量、状态码、耗时、路由信息等）。

8.2 为排障，管理员可能在**限定期限内**开启调试日志。若启用，我们会在控制台或公告中明确告知；未告知即视为未启用。

8.3 上游服务商可能依据其自身政策记录请求内容。请勿提交您无权处理的数据；建议对个人数据做最小化与脱敏处理。

8.4 请求可能跨境传输至境外上游服务商。您应自行确认该等传输符合您所在司法辖区的要求。

8.5 账号信息、支付与日志的具体处理方式详见《隐私政策》，该政策为本协议不可分割的组成部分。
